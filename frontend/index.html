How should it run?

The model downloads once (the small ones are 1 to 2 GB; the 7–8B readers are ~5 GB and want a strong GPU) and is cached, so later scans are quick. A bigger model catches more but runs slower. Needs a browser with WebGPU, such as Chrome or Edge. For findings you can fully trust, use your own API key (Mode 2). The skill’s files never leave your computer.

The key travels over an encrypted connection, is used for this one scan, and is never saved. Because the scan runs on the vendor’s model, the skill’s code is sent there too. Leave Model blank for a sensible default, or name any model your key can use. Want nothing to leave your computer? Use the browser model, or run it on your machine.

No key to paste here. You set that up on your own machine, in a .env file that stays there. See the commands ↓

Prefer to run it on your own machine? Point it at any skill folder. Nothing leaves your computer except the model call you set up.

bash · SkillXray
# 1 · get the code
$ git clone https://github.com/keerthi166/SkillAppropriateness
$ cd SkillAppropriateness

# 2 · set up once
$ python3.13 -m venv .venv
$ .venv/bin/pip install -r requirements.txt

# 3 · pick how the model runs — all local-friendly, no VPN needed
# local & private (recommended): run a model on your own machine with Ollama
$ ollama pull llama3.1:8b
$ .venv/bin/python skillxray.py ./path/to/your-skill --provider ollama

# or use your own cloud key, kept in a .env file that never leaves your machine:
$ echo "OPENAI_API_KEY=sk-…" >> .env
$ .venv/bin/python skillxray.py ./path/to/your-skill --provider openai
# Anthropic instead? add the SDK, then your key:
$ .venv/bin/pip install anthropic && echo "CLAUDE_API_KEY=sk-ant-…" >> .env
$ .venv/bin/python skillxray.py ./path/to/your-skill --provider claude

Pick a capable local model. A small one misses data operations the same way the free in-browser model does — and its context may be too small to read a long file (Ollama defaults low; raise it, e.g. OLLAMA_CONTEXT_LENGTH / num_ctx, or use a cloud key). If a scan reports no findings on a skill that ships code, treat that as inconclusive, not a clean bill of health.
