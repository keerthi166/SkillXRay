Example analysis

A session summarizer

Explore without an API key

coaching-session-summarizer · glebis / claude-skills

What it promises

Turn coaching or therapy transcripts into insights, decisions, and action items.

Two ways to run it

The default workflow asks the active agent to analyze the transcript in-session. The documentation also describes a legacy script for running without an interactive agent.

What the source review found

That optional script sends the transcript to Anthropic’s API when run. Sensitive session content would leave the machine through this API call.

The transcript is inserted into the prompt, then passed to the Anthropic client. This excerpt is shortened; the ellipsis marks omitted prompt instructions.

scripts/summarize_session.py · lines 92–114

prompt = f"""Analyze this coaching session transcript and extract:

{transcript}"""

message = client.messages.create(
    model=MODEL,
    max_tokens=2000,
    system=system_prompt,
    messages=[{"role": "user", "content": prompt}]

Documentation context: SKILL.md → Resources identifies this script as the legacy / headless fallback and describes its direct Anthropic API call. The environment key authenticates that request; reading it is not, by itself, evidence of credential theft.

Research & methodology

SkillXray is a research prototype. Model-assisted analysis examines skill documentation and code for data handling and potential privacy harms. Reports support review; they are not a certification of safety.
